راهنمای نصب ربات قرعه‌کشی

مهم: قبل از دریافت پول واقعی، ربات را با سفارش آزمایشی و حساب آزمایشی تست کنید.
این نسخه بر اساس اسکرین‌شات‌های قابل بازیابی بازسازی شده است؛ متن دقیق تمام تصاویر ممکن است عیناً یکسان نباشد.

۱) فایل ZIP را در GitHub Codespaces داخل پروژه خود Extract کنید.
۲) در ترمینال اجرا کنید:
python3.12 -m pip install --break-system-packages -r requirements.txt

۳) توکن ربات را فقط در Secrets محیط Codespaces ذخیره کنید:
BOT_TOKEN = توکن دریافتی از BotFather
ADMIN_ID = 7762361047

هرگز توکن را در چت یا فایل عمومی قرار ندهید.

۴) اجرا:
python3.12 bot.py

فرمان‌های مدیریت در تلگرام (فقط ادمین):
/status                 وضعیت سفارش‌ها و ظرفیت
/rounds                 فهرست دوره‌ها
/newround Dore2 10000 15000000
                        ساخت دوره جدید و فعال‌کردن آن
/export_pdf             گزارش PDF دوره فعال
/export_pdf 1           گزارش PDF دوره با شناسه ۱

هشدارهای مهم:
- مبلغ پایه ۱۵ میلیون تومان صرفاً از نسخه قبلی/نمونه قابل مشاهده برداشت شده است. پیش از اجرا تأیید کنید که مبلغ دقیق و مدل قیمت‌گذاری همین است.
- عضویت اجباری کانال بررسی نمی‌شود؛ فقط لینک کانال نمایش داده می‌شود.
- پرداخت بانکی به‌صورت خودکار استعلام نمی‌شود؛ ادمین باید رسید و واریز واقعی را خارج از ربات بررسی کند.
- PDF گزارش با فونت پیش‌فرض انگلیسی ساخته می‌شود؛ نام‌های فارسی ممکن است در PDF به‌درستی شکل‌دهی نشوند.
- دیتابیس raffle.sqlite3 را حذف نکنید؛ تمام سوابق دوره‌ها، سفارش‌ها و کدها آنجاست. مرتباً از آن نسخه پشتیبان بگیرید.
- در صورت ری‌استارت Codespace، فایل دیتابیس باید در فضای پایدار پروژه بماند.
