# ربات ثبت‌نام قرعه‌کشی تلگرام

## پیش‌نیاز
- Python 3.10 یا جدیدتر
- توکن ربات از BotFather
- شناسه عددی تلگرام مدیر (ADMIN_ID)

## نصب و اجرا
```bash
python -m venv .venv
source .venv/bin/activate   # ویندوز: .venv\Scripts\activate
pip install -r requirements.txt
```

متغیرهای محیطی را تنظیم کنید:
```bash
export BOT_TOKEN="توکن ربات"
export ADMIN_ID="شناسه عددی تلگرام شما"
export BASE_PRICE="100000"
python bot.py
```

در ویندوز PowerShell:
```powershell
$env:BOT_TOKEN="توکن ربات"
$env:ADMIN_ID="شناسه عددی تلگرام شما"
$env:BASE_PRICE="100000"
python bot.py
```

## فرمان‌های ربات
- `/start` شروع
- `/buy` ثبت سفارش و انتخاب تعداد کد
- `/mycodes` دیدن کدهای صادرشده
- `/orders` فهرست سفارش‌ها (فقط مدیر)

## روند
کاربر تعداد کد را می‌فرستد؛ ربات مبلغ اختصاصی غیررُند می‌دهد؛ کاربر رسید را عکس می‌فرستد؛ مدیر از طریق دکمه تأیید/رد تصمیم می‌گیرد؛ در صورت تأیید، کدهای یکتا صادر می‌شوند.

## نکات مهم
- این نسخه پرداخت بانکی را خودکار تأیید نمی‌کند. مدیر باید مبلغ و تراکنش واقعی را در حساب بانکی بررسی کند.
- مبلغ اختصاصی برای هر سفارش از 100,001 تا 100,999 تومان (یا BASE_PRICE+1 تا BASE_PRICE+999) است و برای هر سفارش یکتا نگه داشته می‌شود.
- نسخه فعلی برای نمونه‌سازی است؛ پیش از استفاده واقعی، امنیت، پشتیبان‌گیری، حریم خصوصی و ثبت سوابق را بررسی کنید.
- فروش بلیت قرعه‌کشی و دریافت پول ممکن است در کشور محل فعالیت نیازمند مجوز یا ممنوع باشد. تا زمانی که قانونی‌بودن و شرایط مجوز روشن نشده، از دریافت پول واقعی استفاده نکنید.
- از این ربات برای فروش یا توزیع کدهای ورود، OTP یا دسترسی به حساب اشخاص استفاده نکنید؛ کدهای صادرشده صرفاً شناسه شرکت در قرعه‌کشی هستند.
